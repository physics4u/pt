# PT — Physics Tuition Manager

This repo is the published website, served by GitHub Pages at
https://physics4u.github.io/pt/.

The source and setup instructions are in **physics4u/pt-code**. Edit there and
copy `web/` here. The only file that differs per deployment is
`js/site-config.js`, which holds the Apps Script `/exec` URL. The passcode is
never stored in this repo.
